# FinCasal AI 💑📊

O **FinCasal AI** é um aplicativo inteligente para gestão financeira de casais, combinando análise de transações, rebalanceamento de orçamento, gamificação e assistente por inteligência artificial (IA) para simplificar e harmonizar as finanças a dois.

---

## 🚀 Tecnologias

- **Frontend**: React + Vite
- **Estilização**: Tailwind CSS / Vanilla CSS
- **Backend / Serverless**: Cloudflare Workers / Functions
- **Persistência / Sync**: IndexedDB + Cloudflare API

---

## 🛠️ Como Executar Localmente

```bash
# Instalar dependências
npm install

# Rodar o servidor de desenvolvimento
npm run dev
```
